# Voice AI site

Простой одностраничный сайт с голосовым вводом, запросом в OpenAI и озвучкой ответа.

## Запуск

```bash
python3 -m http.server 8000
```

Открой `http://localhost:8000`.

## Как использовать

1. Вставь OpenAI API key.
2. Нажми **Начать запись** и скажи запрос.
3. Нажми **Стоп**.
4. Нажми **Отправить в нейросеть**.
5. Нажми **Озвучить ответ**, чтобы услышать голос.

> API key хранится только в текущей сессии браузера и никуда не сохраняется в файлы проекта.
